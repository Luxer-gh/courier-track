# 🚚 CourierTrack: Подсистема управления курьерской доставкой

## 📌 Концепция системы
CourierTrack — это масштабируемая подсистема для интернет-магазинов, предназначенная для автоматизации назначения курьеров, отслеживания статуса доставки в реальном времени, оптимизации маршрутов и генерации отчетности. Система обеспечивает прозрачность процесса доставки как для администраторов магазина, так и для конечных клиентов.

## 🛠 Технологический стек
- **Backend:** Python 3.11+, FastAPI (асинхронный API), SQLAlchemy (ORM)
- **Frontend:** React 18+, TypeScript, Tailwind CSS, React Query
- **База данных:** PostgreSQL 15 (основное хранилище), Redis (кэширование и Celery broker)
- **Фоновые задачи:** Celery (обработка вебхуков, расчет ETA, рассылка уведомлений)
- **Инфраструктура:** Docker, Docker Compose, GitHub Actions (CI/CD)
